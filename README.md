# 🔖 Bookmark Manager

A simple, responsive, and easy-to-use **Bookmark Manager** built with **HTML, CSS, and JavaScript**.

Bookmark Manager allows users to save, organize, search, and manage their favorite websites directly from their browser.

The project is beginner-friendly and demonstrates frontend development concepts such as DOM manipulation, local storage management, and responsive UI design.

---

## ✨ Features

- 🔖 Add new bookmarks
- ✏️ Edit existing bookmarks
- 🗑️ Delete bookmarks
- 🔍 Search bookmarks by name or URL
- 📂 Filter bookmarks by category
- ⭐ Mark bookmarks as favorites
- 🌐 Open saved websites directly
- 💾 Store bookmarks using Browser Local Storage
- 📱 Responsive design for desktop, tablet, and mobile
- 🔗 Automatic URL formatting
- ✅ URL validation

---

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/YOUR-USERNAME/bookmark-manager.git
```

Navigate into the project:

```bash
cd bookmark-manager
```

---

## Run Project

This project does not require any installation or dependencies.

Simply open:

```
index.html
```

in your browser.

For development, you can use VS Code Live Server extension.

# 💾 Local Storage

Bookmark data is stored in the browser using:

```
localStorage
```

Bookmarks remain available after refreshing the browser.

Note:

Clearing browser storage will remove saved bookmarks.
