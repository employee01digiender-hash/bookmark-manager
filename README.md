# 🔖 Bookmark Manager

A simple, responsive, and easy-to-use **Bookmark Manager** built with **HTML, CSS, and JavaScript**.

Save your favorite websites, organize them into categories, search bookmarks, mark favorites, and manage everything directly in your browser.

## ✨ Features

* 🔖 Add new bookmarks
* ✏️ Edit existing bookmarks
* 🗑️ Delete bookmarks
* 🔍 Search bookmarks by name or URL
* 📂 Filter bookmarks by category
* ⭐ Mark bookmarks as favorites
* 🌐 Open saved websites directly
* 💾 Save data using Local Storage
* 📱 Responsive design for desktop, tablet, and mobile
* 🔗 Automatic URL formatting
* ✅ URL validation

## 📂 Categories

Bookmarks can be organized into:

* Work
* Learning
* Social
* Other

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/bookmark-manager.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

No additional packages or dependencies are required.

## 💾 Local Storage

Bookmark data is stored in your browser using `localStorage`.

This means your bookmarks remain available even after refreshing or closing the browser.

> Note: Clearing your browser's local storage will remove the saved bookmarks.
