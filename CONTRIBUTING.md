# 🤝 Contributing to Bookmark Manager

Thank you for your interest in contributing to Bookmark Manager!

We welcome improvements, bug fixes, documentation updates, and new feature suggestions.

---

## 📌 How to Contribute

Follow these steps to contribute:

### 1. Fork the Repository

Create your own fork of the repository on GitHub.

---

### 2. Clone Your Fork

Clone the repository locally:

```bash
git clone https://github.com/YOUR-USERNAME/bookmark-manager.git
```

Navigate into the project:

```bash
cd bookmark-manager
```

---

### 3. Create a New Branch

Always create a separate branch for your changes:

```bash
git checkout -b feature/your-feature-name
```

Examples:

```bash
git checkout -b feature/dark-mode
```

```bash
git checkout -b fix/search-bug
```

---

## 🛠️ Development Guidelines

Before submitting changes:

- Keep the code clean and readable
- Follow the existing project structure
- Do not introduce unnecessary dependencies
- Test changes in the browser
- Make sure responsive layouts still work

---

## 🧪 Testing

Before creating a Pull Request:

- Open `index.html` in your browser
- Test all bookmark features
- Check desktop and mobile layouts
- Verify local storage functionality

---

## 📝 Commit Guidelines

Write clear commit messages.

Good examples:

```bash
git commit -m "Add bookmark search feature"
```

```bash
git commit -m "Fix bookmark deletion issue"
```

Avoid unclear messages:

```
update
changes
fix stuff
```

---

## 🔄 Pull Request Process

When submitting a Pull Request:

Please include:

- Summary of changes
- Reason for the changes
- Testing performed
- Screenshots (if UI changes are included)

A maintainer will review your Pull Request and provide feedback.

---

## 🐛 Reporting Issues

When reporting a bug, include:

- Clear issue description
- Steps to reproduce
- Expected behavior
- Actual behavior
- Screenshots (if applicable)

---

## 💡 Feature Requests

For new feature ideas:

- Explain the problem
- Describe the proposed solution
- Explain why the feature would improve the project

---

Thank you for contributing! 🚀
